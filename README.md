# ♾️ Infinity

### AI-Powered Forex Market Analysis

Infinity is a modern mobile forex analysis application designed to help traders understand market conditions and identify potential trading opportunities using a combination of **AI-powered insights** and **technical analysis**.

Built with React Native and Expo, Infinity brings market analysis, technical indicators, and intelligent insights into a clean, mobile-first experience.

---

## 🚀 Features

* 🤖 **AI-Powered Market Insights**
  Uses AI to analyze technical market data and provide easy-to-understand insights.

* 📊 **Technical Analysis**
  Analyze markets using popular indicators including:

  * RSI
  * MACD
  * EMA
  * Volume

* 📈 **Forex Signals**
  Generate market signals based on technical analysis to help users identify potential opportunities.

* 🌙 **Modern Dark UI**
  A clean, focused interface designed for a comfortable trading-analysis experience.

* 🔐 **Firebase Authentication**
  Secure user authentication and account management.

* ⭐ **Free & Premium Experience**
  Infinity is designed with a freemium model, allowing users to access a limited number of daily signals while premium users can unlock additional capabilities.

---

## 🧠 How Infinity Works

Infinity combines traditional technical analysis with AI.

```text
Market Data
     ↓
Technical Indicators
     ↓
RSI • MACD • EMA • Volume
     ↓
AI Analysis
     ↓
Market Insight
     ↓
Potential Forex Signal
```

The goal is to turn complex market data into insights that are easier for users to understand and act upon.
